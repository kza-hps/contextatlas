# aiCOVENANTS Interaction Reference for ContextAtlas

This reference exists only to help Google Stitch understand the interaction pattern we want to translate into ContextAtlas.

Do not copy aiCOVENANTS branding, colours, covenant language, logo, typography, or identity.

## What to borrow conceptually

The useful reference is the idea of a compact tab/bookmark/pulldown control that reveals progressively deeper context.

For ContextAtlas this becomes Atlas Blinds:

- a top blind that pulls down to reveal the L0 public MAP
- a bottom blind that pulls up to reveal L1-L5 engineering/admin workbench layers
- a collapsed state where the live product remains visible
- a peek state that gives a quick coordinate and explanation
- half/full states for deeper inspection
- an opacity control so the blind can be transparent, frosted, or opaque

## Translation into ContextAtlas

aiCOVENANTS = reference for progressive reveal only.

ContextAtlas = transparent overlay and topology HUD over a live app.

The blind should feel like a glass/cartography layer that slides over the product surface, not like a conventional drawer or modal.

The most important first-user screen is Layer Zero: the MAP. This should be the public-facing orientation map for the product journey.

L1-L5 should be progressively revealed for admin, engineers, QA, support operations, and AI coding agents.
